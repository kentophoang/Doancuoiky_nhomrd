# 🧠 E-commerce Website Project (Dự án Website Thương mại Điện tử)

This project is a comprehensive e-commerce website built using PHP, MySQL, and various other technologies. It provides a robust platform for managing products, orders, customers, and administrators. The website features a user-friendly interface, secure payment processing, and efficient order management.

*Dự án này là một trang web thương mại điện tử toàn diện được xây dựng bằng PHP, MySQL và nhiều công nghệ khác. Nó cung cấp một nền tảng mạnh mẽ để quản lý sản phẩm, đơn hàng, khách hàng và quản trị viên. Trang web có giao diện thân thiện với người dùng, xử lý thanh toán an toàn và quản lý đơn hàng hiệu quả.*

## 🚀 Features / Tính năng
- **User registration and login functionality** / *Chức năng đăng ký và đăng nhập người dùng*
- **Product browsing and searching** / *Duyệt và tìm kiếm sản phẩm*
- **Shopping cart and checkout management** / *Quản lý giỏ hàng và thanh toán*
- **Order history and tracking** / *Lịch sử và theo dõi đơn hàng*
- **Administrator dashboard for managing products, orders, and customers** / *Bảng điều khiển quản trị viên để quản lý sản phẩm, đơn hàng và khách hàng*
- **Secure payment processing using various payment gateways** / *Xử lý thanh toán an toàn sử dụng các cổng thanh toán khác nhau*
- **Product reviews and ratings system** / *Hệ thống đánh giá và xếp hạng sản phẩm*
- **Category management for products** / *Quản lý danh mục sản phẩm*

## 🛠️ Tech Stack / Công nghệ sử dụng
- **Frontend / Giao diện người dùng:** HTML, CSS, JavaScript, Bootstrap, Font Awesome
- **Backend / Máy chủ:** PHP, MySQL, PDO
- **Database / Cơ sở dữ liệu:** MySQL
- **Server / Máy chủ web:** Apache
- **Payment Gateways / Cổng thanh toán:** Various (e.g., PayPal, Stripe) / *Khác nhau (ví dụ: PayPal, Stripe)*
- **Libraries / Thư viện:** Bootstrap, Font Awesome, jQuery

## 📦 Installation / Cài đặt
To install the project, follow these steps:
*Để cài đặt dự án, hãy làm theo các bước sau:*

1. Clone the repository using Git: / *Sao chép kho lưu trữ bằng Git:*
   ```bash
   git clone https://github.com/your-repo/ecommerce-website.git
   ```
2. Create a new database in your MySQL server and import the provided SQL file. / *Tạo một cơ sở dữ liệu mới trong máy chủ MySQL của bạn và nhập tệp SQL được cung cấp.*
3. Update the database connection settings in `db.php` to match your database credentials. / *Cập nhật cài đặt kết nối cơ sở dữ liệu trong `db.php` để khớp với thông tin đăng nhập cơ sở dữ liệu của bạn.*
4. Install the required libraries and dependencies using Composer: / *Cài đặt các thư viện và phụ thuộc cần thiết bằng Composer:*
   ```bash
   composer install
   ```
5. Configure the payment gateways and other third-party services as needed. / *Cấu hình các cổng thanh toán và các dịch vụ của bên thứ ba khác nếu cần.*

## 💻 Usage / Sử dụng
1. Start the Apache server and navigate to the project directory in your web browser. / *Khởi động máy chủ Apache và truy cập vào thư mục dự án trên trình duyệt web của bạn.*
2. Register as a new user or log in to an existing account. / *Đăng ký người dùng mới hoặc đăng nhập vào tài khoản hiện có.*
3. Browse products, add to cart, and checkout. / *Duyệt sản phẩm, thêm vào giỏ hàng và thanh toán.*
4. Manage orders, products, and customers as an administrator. / *Quản lý đơn hàng, sản phẩm và khách hàng với tư cách là quản trị viên.*
